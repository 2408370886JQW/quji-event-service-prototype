# 平台命名方案与后台数字化架构设计说明

## 一、平台命名方案

为配合用户端现有品牌“漫圈”，并满足平台未来承接动漫展览、国风文创、电竞赛事、青年音乐节及数字潮玩等多元文化活动的需求，提出以下兼具辨识度与延展性的命名方案：

| 推荐名称 | 英文标识 | 命名寓意与适用场景 | 优势分析 |
| :--- | :--- | :--- | :--- |
| **趣集**（首推） | **Quji** | “有趣的人与多元文化在此汇聚”。既契合二次元与青年圈层，又具备文创大市集、展会与大型文旅活动的承载力。 | 两字简明，极具互联网科技感；易读好记，天然契合 Apple 极简与高质感设计调性。 |
| **潮汇** | **Chaohui** | 潮流文化汇聚之所，凸显青年活力与新型文化业态。 | 适合延展至文商旅综合体、夜间文化消费等多业态场景。 |
| **原点活动** | **Origin Events** | 寓意青年原创、创意策源地与文化数字化服务的基石。 | 专业沉稳，面对文旅指导及主办方交流时兼具规范感与科技感。 |
| **漫潮汇** | **ManChao** | 平衡动漫原生圈层（漫）与潮流文化（潮），与“漫圈”用户端形成天然品牌矩阵。 | 呼应性强，便于用户与主办方建立直观认知。 |

## 二、双端业务闭环与字段映射关系

后台平台不直接面向普通观众提供服务，而是作为**主办方运营、辅助初核与文旅合规调阅的核心工作台**，精准承接用户端产生的业务数据：

| 用户端（漫圈 / 次元地标）数据源 | 后台平台（趣集）业务承接环节 | 处理机制与脱敏规范 |
| :--- | :--- | :--- |
| **选票与支付**（普通票 / Coser 票） | **活动票务与规模监控** | 自动形成订单电子底册与活动参与人次脱敏统计，严密监控现场承载量。 |
| **实名认证 & 人脸活体比对** | **实名认证状态核验** | **落实最小必要原则：** 原始身份证件影像与人脸生物特征实时比对后销毁，后台仅留存脱敏姓名、掩码证件号及认证通过标识。 |
| **Coser 角色与服装登记** | **内容与道具辅助初核** | 归集角色名、服装描述、道具尺寸材质及参考图。平台提供规则辅助核验，由主办方按现场规则最终确认。 |
| **高关注风险标记**（长钝器/拟真模型） | **安全防线联动** | 自动标记“需现场安保协同”，提供特定道具安全提示，便于现场安检关口点对点复验。 |
| **入场电子核销码（动态 QR）** | **现场核销与签到记录** | 关联购票身份与已审核角色档案，现场扫码即完成比对留痕，确保“人、证、服”一致。 |

## 三、文旅与公安权限架构设计

严格依据方案要求，平台坚持**“服务优先、不替代行政审批、不承接法定监管”**的基本定位，设立分级授权机制：

```
                    ┌──────────────────────────────┐
                    │     趣集·数字化协同平台      │
                    └──────────────┬───────────────┘
                                   │
         ┌─────────────────────────┴─────────────────────────┐
         ▼                                                   ▼
┌─────────────────────────────────┐         ┌─────────────────────────────────┐
│     文旅业务指导（主视角入口）    │         │     公安治安协同（次级入口）    │
├─────────────────────────────────┤         ├─────────────────────────────────┤
│ • 试点活动综合运行态势与总览     │         │ • 仅在确有必要时发起最小范围调阅│
│ • 主办方活动信息与规则电子档案   │         │ • 高风险长钝器 / 拟真道具协同   │
│ • 角色/服装提报统计与初核跟踪   │         │ • 现场安防与大客流疏导预案调阅 │
│ • 试点复盘脱敏数据集导出         │         │ • 独立授权审批、事由登记与全审计│
└─────────────────────────────────┘         └─────────────────────────────────┘
```

1. **文旅部门（业务指导主体）：**
   - 可常态化调阅活动基础档案、参与人次走势、角色提报汇总及合规留痕日志；
   - 重点掌握文化内容导向与特色文化融合情况，为试点总结与优化提供数据支撑。
2. **公安部门（协同联动主体）：**
   - 不设常驻全量数据库浏览权限；
   - 仅在涉及现场安保布防、超大客流预警或高仿真违规道具核实等具体安全业务时，以“一事一审、专人专责、限定范围”的形式发起受控调阅。
3. **全流程留痕与审计：**
   - 系统详细记录每一次调阅的操作人、部门、时间、IP、调阅对象与业务事由；
   - 支持不可逆审计日志追溯，杜绝任何批量拉取与滥用风险。
