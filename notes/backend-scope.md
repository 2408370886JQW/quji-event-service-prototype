# 后台原型范围依据（方案第21—25页）

- 活动管理：支持活动创建、发布、信息维护、资料上传、计划安排、状态管理与电子档案；统一管理报名、票务、嘉宾、参展、工作人员及现场签到核验。
- 活动资料与规则：主办方提交活动时间、地点、规模、内容及组织信息；设置活动参与规则、入场要求与禁止事项。
- 角色服装道具管理：统一管理活动参与者的角色、服装、道具登记，提供辅助初核；主办方按活动规则最终确认；线上登记、信息确认、现场核验衔接。该流程为活动组织服务，不替代行政审批、监管职责。
- 用户与权限：统一身份、账号、权限控制，按角色职责进行分级服务。
- 数据管理：归集活动、用户、场馆、票务、商户、签到与运行数据；分类分级保护。
- 综合分析：活动数量、参与人数、票务、参展商、热度及平台运行分析的可视化。

本轮原型优先聚焦：文旅主视角的总览、活动审核、角色/服装/道具辅助初核、受控合规调阅、审计日志；公安只保留“协同联动/受控调阅”次级入口。
