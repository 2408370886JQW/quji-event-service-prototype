# 趣集文化活动协同平台｜第二轮界面重构决策

## 模式

**Redesign · Preserve（保留式重构）**。保留活动中心化的信息架构、角色权限、活动资料、票务、现场核验、角色服装道具和档案归集等产品结构；重构存在问题的视觉语言、断行规则与“查看/管理”的实际操作路径。

## 需要保留

- “趣集”名称、三语入口、活动档案模块、角色和权限结构。
- 现有材料、票务、现场及档案的业务字段与状态口径。
- 既有登录、活动详情、主办方资料、数据中心、通知与设置入口。

## 需要改善

- 中文标题、机构名称、日期、金额、编号和状态作为完整语义 token 呈现，禁止把最后一个字、日期尾段或数值单位折到下一行。
- 说明文字按句子或短语断行；例如“主体档案用于活动资料归集与服务协同”与“不替代相关法定审批或登记程序”分别占行。
- “查看 / 管理 / 补充”由泛化确认弹窗改为三步任务抽屉：查看当前资料 → 补充或更新 → 提交并写入记录。
- 将侧栏收起控件改为紧凑图标按钮；将图标大色块、厚投影、过大圆角和泛化确认框替换为克制的业务工具 UI。

## 移除

- 与操作无关的“确认”说明型弹窗。
- 宽大的“收起菜单”文字按钮。
- 以图标大色块、厚阴影、渐变光效制造层次的模板化手法。

## 视觉系统

| 维度 | 方案 |
|---|---|
| 视觉语言 | 克制的信息架构式业务后台；强调阅读、对齐与可操作性 |
| 色彩 | 暖灰背景 #F7F8FA、深墨文本 #18212F、单一操作蓝 #245FC4、语义绿/琥珀/赤仅用于状态 |
| 字体 | PingFang SC / Microsoft YaHei / Noto Sans SC 的中文优先系统栈 |
| 间距 | 8px 网格，内容模块 16px 或 20px 内距 |
| 圆角 | 控件 6px，页面容器 8px；不使用大面积 16px+ 软卡片 |
| 阴影 | 默认无阴影；抽屉与浮层仅使用一层低对比投影 |
| 动效 | 140–200ms、仅用于点击/打开/收起反馈；支持减少动态效果 |

## 风险与回退

最高风险是将通用操作弹窗替换为任务抽屉时破坏原动作覆盖。处理方法是保持 `ActionButton` 对外参数不变，内部用统一任务流承接全部入口，构建和浏览器点击逐一验证。
